# Desentupidora Universo 24hrs

Site da Desentupidora Universo 24hrs (Astro estático, publicado na Vercel), baseado na estrutura do site da Dutra Hidráulica.

- Dados da empresa (nome, telefone, domínio, GTM): `src/data/site.ts`
- Serviços: `src/data/servicos.ts`
- Cidades (geram `/desentupidora-em-<cidade>/`): `src/data/cidades.ts`
- Fotos reais: ver `fotos/README.md`
- Artigos: `src/content/blog/`

```bash
npm install
npm run dev     # desenvolvimento
npm run build   # gera a pasta dist/
```
