# Fotos reais dos serviços

Coloque as fotos de cada serviço na pasta com o nome dele:

| Pasta | Serviço |
|---|---|
| `desentupimento-de-vaso-sanitario/` | Vaso sanitário |
| `desentupimento-de-ralo/` | Ralo |
| `desentupimento-de-esgoto/` | Esgoto (esta também vira o fundo do topo da home) |
| `desentupimento-de-pia/` | Pia |
| `desentupimento-de-cano/` | Cano e tubulação |
| `limpa-fossa/` | Limpa fossa (esta também aparece em "Por que a Universo 24hrs") |

No build, a primeira foto (em ordem alfabética) de cada pasta é otimizada e salva em
`src/assets/fotos/<pasta>.jpg`. Para trocar uma foto, apague esse `.jpg` gerado.

Enquanto uma pasta estiver vazia, o site mostra o ícone do serviço no lugar da foto.
